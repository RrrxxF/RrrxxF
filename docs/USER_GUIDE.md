# 用户指南（S1）

DesignWorkbench 0.2.0 增加了本地项目管理和六个工作区入口。安装方法见 [非程序员安装说明](SETUP_FOR_NON_DEVELOPER.md)。

1. 打开 **工作台**，点击 **新建项目**，输入名称后保存。
2. 点击顶部的 **全部资源** 下拉框，可进入某个项目，也可切回全部资源；重启后会记住选择。
3. 在项目卡片上使用铅笔图标改名、文件夹图标归档、× 移出项目列表。归档项目在页面下方可恢复。移出项目列表目前是数据库软删除，界面暂不提供恢复入口，操作前会确认。
4. 左侧可进入图标库、组件库、Design Tokens、设计图库和收集箱。S1 只提供真实入口和空状态，素材功能会在后续阶段接入。
5. 在 **设置 → 本地数据** 可查看当前应用版本及数据库所在目录。项目默认只存放在这台电脑。

浏览器页面仅用于查看布局；项目管理要在 Windows 桌面程序中使用。开发期间无需每次改动都下载安装包，只有里程碑 Windows 实机验证时才需要更新。
