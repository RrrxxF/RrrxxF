# 用户指南（S2）

DesignWorkbench 0.3.0 在本地项目管理基础上，增加了静态素材导入与整理。安装方法见 [非程序员安装说明](SETUP_FOR_NON_DEVELOPER.md)。

1. 打开 **工作台**，点击 **新建项目**，输入名称后保存。
2. 点击顶部的 **全部资源** 下拉框，可进入某个项目，也可切回全部资源；重启后会记住选择。
3. 在项目卡片上使用铅笔图标改名、文件夹图标归档、× 移出项目列表。归档项目在页面下方可恢复。移出项目列表目前是数据库软删除，界面暂不提供恢复入口，操作前会确认。
4. 打开 **图标库**、**组件库** 或 **设计图库**，点击 **导入文件**，可一次选取多个 SVG、PNG、JPEG、WebP、GIF 或 BMP 文件；也可将文件拖入应用窗口。导入时能看到已完成数量并取消后续文件；当前文件也会检查取消请求。
5. 使用搜索框查找中文/英文名称、原文件名或标签；可按文件夹、标签、收藏筛选。点击素材卡片可改名、设置标签、收藏，并将素材关联到多个项目或文件夹。顶部项目切换器决定当前列表范围和新导入素材所属项目。
6. 新建文件夹时，先选择顶部项目；“全部资源”下创建的是全局文件夹。相同内容只存一份原始文件，但可以创建不同的素材记录和项目关联。移出素材列表是软删除，不会立即清除原文件。
7. **Design Tokens** 和 **收集箱** 仍显示空状态；SVG 属性编辑、Figma 复制粘贴和备份将在后续阶段接入。
8. 在 **设置 → 本地数据** 可查看当前应用版本及数据库所在目录。项目和原始素材默认只存放在这台电脑。

单个文件上限为 100 MiB。内容损坏或格式伪装的文件会被拒绝；导入失败的文件名会显示在界面中。浏览器页面仅用于查看布局；素材操作需在 Windows 桌面程序中使用。开发期间无需每次改动都下载安装包，只有里程碑 Windows 实机验证时才需要更新。
